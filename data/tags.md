# Tag relation test

Descry's second relation sigil. Where `[[wiki links]]` point at one
file, `#tags` name a subject any number of notes can share.

A simple tag: #graph-theory should be highlighted.

Mid-paragraph: see #rendering for the font work, or
#markdown for the parser.

Nested paths are one tag: #math/algebra.

A `#` needs a boundary: C# and issue#12 stay plain text.

A bare # on its own, and punctuation #! after one, stay plain.

## This heading is not a tag

Mixed with a wiki link: [[wikis]] plus #markdown.
